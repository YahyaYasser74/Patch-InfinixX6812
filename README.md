# Patch-InfinixX6812
Fixation for GSI Bugs while experiencing them!
Are you experiencing lags or having choopy animations while scrolling? or... OTG, LED Indicator, RAW50Mps, and stuff arent working anymore in GSI ROMs? Well this module is for you!
# What makes this module special than other Fixation modules for this device?
Well...This one i combined and revamped scripts, removed some garbage scripts' lines, readding new ones, etc! also what makes this special is about its new stuff, such as Kernel Optimzation (fixes the low ram property and fix the aggressively lmk, turning off SWAP as it turns out for reducing eMMC lifespan), Smoothness (removing the stock overlay that was included in the module results in good performance and no slowness anymore, which i removed it from the module, about battery capacity, i need some feedbacks if anyone needed this back then) Good Tunes in Virtual RAM (while GSI roms is generic, it may not appling to some bad tunes from stock kernels, so i tuned it for good own) Custom Thermal (got it from 4PDA, this just optimizes the stock thermal configuration which is found in "/vendor/etc/.tp/thermal.conf" as it removes bottleneck, making the experience more fluent)
